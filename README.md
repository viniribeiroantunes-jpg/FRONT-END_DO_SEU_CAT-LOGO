# 🎵 Sistema Musical

## 📌 Sobre o projeto

O **Sistema Musical** é um projeto de Front-End desenvolvido para organizar e gerenciar informações sobre artistas e músicas. O sistema apresenta uma interface simples e intuitiva, permitindo navegar entre as páginas e visualizar as funcionalidades disponíveis.

## 🚀 Funcionalidades

- **Login:** tela inicial de acesso ao sistema.
- **Menu principal:** acesso às principais funcionalidades.
- **Cadastro de artistas:** formulário com nome, gênero musical, país e foto.
- **Cadastro de músicas:** página para adicionar informações musicais.
- **Biblioteca musical:** listagem e visualização das músicas cadastradas.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## ▶️ Como executar

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `login.html` no navegador.
4. Navegue pelas páginas do sistema.

## 🎯 Objetivo

O objetivo do projeto é colocar em prática os conhecimentos de desenvolvimento Front-End, utilizando HTML e CSS para criar páginas organizadas, funcionais e com uma identidade visual consistente.
